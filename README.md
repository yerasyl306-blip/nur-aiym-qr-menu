# НҰР-АЙЫМ QR мәзірі

## Render баптауы

Render Environment Variables ішіне мыналарды қосыңыз:

- `ADMIN_LOGIN` және `ADMIN_PASSWORD` — әкімші деректері (міндетті түрде әдепкі мәндерді ауыстырыңыз);
- `KITCHEN_PASSWORD=02` — асүй панелінің құпиясөзі;
- `PRINTER_KEY` — ұзын, кездейсоқ құпия кілт.

Сілтемелер: `/admin` — әкімші панелі, `/kitchen` — асүй панелі, `/?type=pickup` — самовывоз, `/?type=delivery` — жеткізу.

## XPrinter 58 USB

1. Касса компьютеріне XPrinter 58 драйверін орнатып, Windows-та принтердің дәл атауын біліңіз.
2. Node.js орнатыңыз, осы репозиторийді компьютерге көшіріңіз.
3. `MENU_URL`, `PRINTER_KEY`, `XPRINTER_NAME` ортаның айнымалыларын орнатып, `node printer-agent.js` командасын іске қосыңыз.

Агент әр 2 секунд сайын сервердің жабық кезегін тексереді және жаңа тапсырысты USB-принтерге жібереді. Ол браузер терезесін не басып шығару диалогын ашпайды.
